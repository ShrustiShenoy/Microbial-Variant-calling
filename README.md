# Microbial-Variant-calling
This project investigates the genomic variations in Escherichia coli exposed to chloramphenicol, focusing on identifying Single Nucleotide Polymorphisms (SNPs) that contribute to antibiotic resistance. Whole-genome sequencing data from wild-type and antibiotic-treated strains were retrieved from the NCBI Sequence Read Archive (SRA) and analyzed using bioinformatics pipelines.
# Objectives
Compare genomic variations between wild-type and chloramphenicol-exposed E. coli strains.
Identify and annotate SNPs linked to antibiotic resistance.
Analyze the mutational patterns and functional impact of variations.
Visualize genetic variations using ggplot2 in R.
